
Общая концепция



Название (рабочее): FitMind AI

Тип: Web-приложение (SPA) + адаптивная вёрстка (Mobile First)

MVP-фичи:



1. Создание своих тренировок (упражнения, подходы, вес, повторения)

2. Генерация тренировок через нейросеть (пол, вес, уровень подготовки)

3. Калораж + составление рационов

4. Калькулятор веса (1 ПМ и рабочие веса)

5. Авторизация (JWT, роли: пользователь)



---



Фронтенд (клиентская часть)



Технологии (рекомендуемые)



· React / Vue / Svelte (лучше React, т.к. много UI-компонентов)

· Адаптивная вёрстка — CSS Grid / Flex, медиазапросы, mobile-first подход

· Состояние — Redux Toolkit (или Pinia для Vue)

· HTTP-клиент — Axios или fetch



Страницы / Экраны



Страница Описание

Регистрация / Логин Формы, валидация, восстановление пароля

Дашборд (главная) Краткая статистика (калории за день, последняя тренировка, прогресс по весам)

Конструктор тренировок Добавление упражнений (выбор из базы или своё название), задание подходов, повторений, веса. Сохранение как шаблона

Мои тренировки Список созданных тренировок, запуск (отметка выполнения), история

AI-генератор Форма: пол, вес, уровень (новичок/средний/продвинутый), цель (похудение/масса/сила), доп. ограничения (травмы, инвентарь). На выходе — готовая тренировка (можно сохранить)

Калории и рацион Дневник еды (поиск продуктов, граммы), отображение БЖУ. AI-генерация рациона на день (по калориям и предпочтениям)

Калькулятор веса Два режима: 1 ПМ (вес × повторения) и расчёт рабочего веса на заданный % от ПМ

Профиль Пол, вес, рост, возраст, уровень активности (для калорий)



Требования к интерфейсу



· Кнопки достаточно крупные (для пальца)

· Темная/светлая тема (опционально)

· Графики (прогресс весов, калорий) — Chart.js или Recharts



---



Бэкенд (серверная часть)



Технологии (рекомендуемые)



· Node.js + Express (быстрый старт) или Python + FastAPI (удобно для нейросетей)

· База данных — PostgreSQL (основная) + Redis (для кэша и очередей AI)

· Авторизация — JWT access + refresh токены (bcrypt для паролей)

· Файловое хранилище — S3 или локальное (для аватарок)



Структура базы данных (основные таблицы)

users (id, email, password_hash, name, sex, weight, height, age, activity_level, role)

exercises (id, name, muscle_group, is_custom, created_by_user_id)

workout_templates (id, user_id, name, created_at)

workout_exercises (id, template_id, exercise_id, sets, reps, weight)

workout_sessions (id, user_id, template_id, date, duration_minutes)

workout_results (id, session_id, exercise_id, sets_done, reps_done, weight_used)

food_items (id, name, calories, protein, fat, carbs, user_id (NULL если общие))

meal_logs (id, user_id, food_id, grams, date)

calorie_goals (id, user_id, daily_goal, date)

ai_generation_logs (id, user_id, type, input_params, output_json, created_at)



API endpoints (основные)



Метод Эндпоинт Описание

POST /auth/register Регистрация

POST /auth/login Вход (возвращает JWT)

GET /user/profile Получить профиль

CRUD /workouts/templates Свои тренировки

POST /workouts/sessions/:id/complete Завершить тренировку (сохранить результат)

POST /ai/generate-workout Принимает параметры → возвращает JSON-тренировку

POST /ai/generate-meal-plan Параметры (калории, диета) → список продуктов и приёмов пищи

GET /calculator/1rm weight, reps → 1 ПМ

POST /calculator/working-weight 1rm, percentage → рабочий вес

CRUD /food Добавить/редактировать/удалить продукты (личные и общие)

GET /food/search?query=... Поиск продуктов (LIKE или полнотекстовый)



Интеграция нейросети



· Вариант 1 (легко): Использовать OpenAI GPT (API) с хорошим промптом. На выходе — JSON, который парсится в тренировку/рацион.

· Вариант 2 (своя): Небольшая fine-tuned модель (например, на базе Llama 3), но это дольше.

· Что делает бэкенд: получает запрос → формирует промпт (включает данные пользователя) → вызывает AI → валидирует и сохраняет ответ → возвращает клиенту.



Очереди и кэш

AI-генерацию лучше ставить в очередь (Bull/Redis), чтобы не блокировать ответ при большой нагрузке.

· Список упражнений и продуктов кэшировать в Redis.

Дополнительные рекомендации «по ходу»

· Социальная механика — друзья, челленджи, публичные тренировки

Что потребуется для запуска MVP (минимальная версия)



1. Фронт: авторизация, конструктор тренировок, просмотр истории.

2. Бэк: регистрация, CRUD тренировок, сохранение результатов.

3. AI: простейшая генерация тренировки по 2–3 параметрам (можно заглушкой для старта).

4. Калькулятор весов — простая формула Бжицки.

5. Калории: ручное добавление продуктов + таблица (загрузить стартовый CSV с базой).
