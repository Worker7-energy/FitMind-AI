# FitMind AI Mobile

Мобильное приложение для трекинга тренировок, питания и прогресса с AI-помощником.

## Требования

- Среда React Native для Android (Android SDK, Java, настроенный эмулятор или физическое устройство)
- Node.js

## Запуск

```bash
npm install
npm run android
```

Приложение будет использовать Metro на порту `8088`. 

## Бэкенд

Требуются два запущенных сервиса:

- **Auth** – порт `8080`
- **Main** – порт `8081`

Адреса серверов можно изменить в самом приложении в настройках.
По умолчанию для эмулятора Android используются `http://10.0.2.2:8080` и `http://10.0.2.2:8081`.
